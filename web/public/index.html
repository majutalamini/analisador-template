Como funciona

Três passos, do envio à correção. Não é preciso instalar nada.

  1. 1

    Envie o template

    Cole o link do Google Docs ou arraste o arquivo .docx. O documento do Google precisa estar compartilhado como "Qualquer pessoa com o link".

  2. 2

    O analisador confere cada tag

    Todas as tags do texto são comparadas com o modelo de referência do sistema, o mesmo que define as variáveis aceitas.

  3. 3

    Corrija pelo trecho indicado

    Cada problema vem com a mensagem, o trecho e a linha. Com o link do Google Docs, "Ir para o trecho" copia o texto e abre o documento: é só Ctrl+F e colar.

O que é verificado

  • <<[Variavel]>>Variáveis com nome errado ou que não existem no sistema
  • <<if [...]>>Condições que usam campos inexistentes
  • <<foreach [...]>>Laços com item ou coleção inválidos
  • <</if>>Blocos abertos sem fechamento, ou fechados no lugar errado
  • <<image [...]>>Imagens digitadas como texto em vez de inseridas como imagem

    Dúvidas frequentes

    Por que o documento do Google Docs precisa estar público?

    O analisador lê o documento pela exportação pública do Google. No Docs, clique em Compartilhar e, em "Acesso geral", escolha "Qualquer pessoa com o link" como Leitor. Se preferir não compartilhar, baixe como .docx e envie o arquivo.

    Meu arquivo é enviado para algum servidor?

    Não. A análise e a compressão acontecem no seu navegador. No caso do link do Google Docs, o servidor só repassa a exportação pública do documento.

    O que quer dizer "não existe no modelo de referência"?

    A variável, condição ou laço não está entre os que o sistema reconhece. Confira a grafia na aba Variáveis. Se for uma variável nova que o sistema já aceita, cadastre na aba Personalização.

    As variáveis de foreach não retornam valor. Por quê?

    Elas só funcionam dentro de um bloco <<foreach>>. Fora dele, ficam vazias. A aba Variáveis tem estruturas prontas com o bloco completo para copiar.

    Tenho um arquivo .doc antigo. Funciona?

    Não. Abra o arquivo no Word e use "Salvar como" no formato .docx.

    O arquivo passou de 2 MB. O que faço?

    Use a aba Compressor. Ela reduz as imagens do documento sem mudar o texto. Depois, clique em "Analisar este arquivo" para conferir o resultado.
